# Code of Conduct

This project adopts the **Contributor Covenant version 2.1** as its code of conduct.
All participants are expected to uphold the standards described in that document.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Please raise conduct concerns via a GitHub issue addressed to the maintainers,
or contact the maintainers directly through GitHub.
